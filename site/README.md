# FestVisuals — сайт

Статический сайт без сборки: `index.html` + `assets/`. Можно открыть
файл напрямую или захостить на GitHub Pages/Netlify/Vercel как есть.

Перед публикацией замените `GITHUB_OWNER`/`GITHUB_REPO` в
`assets/script.js` на свои — оттуда подтягивается ссылка на последний
релиз (кнопка "Скачать бесплатно").

Кнопка "Купить" (paid) сейчас ведёт на заглушку `#paid-checkout` —
подключите туда свою страницу оплаты/выдачи лицензии, когда она будет
готова (см. также `../launcher/README.md`, раздел про лицензии).
