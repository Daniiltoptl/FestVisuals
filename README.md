# FestVisuals

Монорепозиторий из трёх частей:

- **`visuals/`** — сам клиент (Fabric-мод для Minecraft). Сборка через
  Gradle (`./gradlew build` из этой папки). Подробности — в
  `visuals/CLAUDE.md`.
- **`launcher/`** — лаунчер, который скачивает нужный jar из последнего
  GitHub Release и кладёт его в `mods/`. Подробности — в
  `launcher/README.md`.
- **`site/`** — статический сайт-витрина с тарифами (Free/Paid).
  Подробности — в `site/README.md`.

## Тарифы

На данный момент есть только **Free**-редакция. Всё, что будет добавлено
сверх неё в будущем, планируется как **Paid**. Разделение сборки на
free/paid артефакты пока не реализовано на уровне Gradle — это
следующий шаг (см. `.github/workflows/release.yml`, комментарий в шаге
"Prepare release asset").

## CI/CD

- `.github/workflows/build.yml` — собирает мод при пуше в любую ветку
  кроме `main` и при пул-реквестах, чтобы ловить ошибки компиляции
  раньше релиза. Артефакт прикладывается к прогону сборки.
- `.github/workflows/release.yml` — при пуше в `main`:
  1. увеличивает патч-версию в `visuals/gradle.properties`;
  2. коммитит бамп версии обратно в `main` (с `[skip ci]`, чтобы не
     зациклиться);
  3. ставит git-тег `vX.Y.Z`;
  4. собирает мод;
  5. публикует GitHub Release с приложенным `festvisuals-free.jar`.

  Лаунчер и сайт берут ссылку на free-jar именно из последнего релиза
  этого репозитория (`GET /repos/OWNER/REPO/releases/latest`).

## Что важно знать перед первым релизом

- Замените `visuals/LICENSE` — сейчас там временная заглушка.
- Замените `YOUR_GITHUB_USERNAME`/`GITHUB_OWNER` в `launcher/config.example.json`
  и `site/assets/script.js` на реальный аккаунт/репозиторий.
- Проверка лицензионного ключа для Paid-тарифа в лаунчере — это только
  клиентская заглушка (см. `launcher/README.md`). Для реальной продажи
  платной версии нужен свой backend с базой лицензий и, вероятно,
  приватное хранилище для paid-jar (публичные GitHub Release assets
  доступны всем по прямой ссылке).
- Первый прогон `release.yml` стоит сделать вручную под присмотром —
  проверьте, что `./gradlew build` в `visuals/` вообще проходит в вашем
  окружении (в среде, где готовился этот патч, не было доступа к сети,
  поэтому сборка не проверялась компилятором ни разу).
